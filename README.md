# Implementación y evaluación de filtros digitales

Este repositorio contiene un ejemplo en Python que implementa filtros digitales (Butterworth IIR y FIR con ventana) y analiza su efecto sobre una señal compuesta con ruido.

Archivos incluidos:
- filter_analysis.py : Script principal con diseño y aplicación de filtros.
- Imágenes: gráficos de la señal original, espectros, respuestas en frecuencia y señales filtradas.
